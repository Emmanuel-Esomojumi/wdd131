# WDD 131 – Dynamic Web Fundamentals

This repository contains coursework and projects for **WDD 131: Dynamic Web Fundamentals** at BYU-Pathway Worldwide.

## Course Overview
WDD 131 builds on **WDD 130 (Web Fundamentals)** and introduces **JavaScript** for creating dynamic, interactive, and responsive websites. The course emphasizes usability, accessibility, and best practices in front-end web development.

Students learn how to:
- Build responsive web pages using HTML and CSS
- Use JavaScript to respond to user events
- Dynamically update page content
- Create interactive user experiences

## Prerequisite
- WDD 130: Web Fundamentals

## Tools & Technologies
- HTML5
- CSS3
- JavaScript (ES6+)
- Visual Studio Code
- GitHub & GitHub Pages

## Repository Structure
This repository includes:
- Weekly assignments
- Practice activities
- Course project files

Each folder corresponds to a specific week or assignment in the course.
